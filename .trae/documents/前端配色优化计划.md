# 前端页面优化计划 - 日志查看配色优化

## 当前状态分析

### 现有配色方案
- **基础背景**: #0b1117 (深蓝黑)
- **表面色**: #151c24, #273241
- **文本色**: #e6edf3 (浅灰白)
- **柔和文字**: #8b9bb0
- **日志级别颜色**:
  - Info: #7aa2f7 (蓝色)
  - Warn: #e0af68 (橙色)
  - Error: #f7768e (红色)
  - Debug: #9ece6a (绿色)
  - Accent: #bb9af7 (紫色)

## 优化目标
提升日志查看体验，优化配色使其：
- 更适合长时间查看日志
- 层级分明，重点突出
- 减少视觉疲劳
- 提高可读性

## 优化计划

### 1. 配色方案全面优化
**目标文件**: `web/app.css`

#### 1.1 背景色优化
- **问题**: 当前深蓝黑背景 (#0b1117) 可能在某些显示器上对比度不够
- **优化方案**: 
  - 调整为更深的纯黑 #0d0d0d 或使用柔和的蓝黑 #0a0e14
  - 增强背景层次感

#### 1.2 文本对比度优化
- **问题**: 部分文本颜色对比度可能不够理想
- **优化方案**:
  - 主文本: 从 #e6edf3 调整为更亮的 #f0f6fc
  - 次要文本: 从 #8b9bb0 调整为 #8892a4

#### 1.3 日志级别颜色优化
- **目标**: 更鲜明的颜色区分，减少视觉疲劳
- **优化方案**:
  - **Info**: #7aa2f7 → #79c0ff (更亮更清新的蓝)
  - **Warn**: #e0af68 → #ffa657 (更鲜明的橙)
  - **Error**: #f7768e → #ff6b6b (更醒目的红)
  - **Debug**: #9ece6a → #a5d6a7 (更柔和的绿)

### 2. 日志卡片样式优化
**目标文件**: `web/app.css`

#### 2.1 日志卡片增强
- 添加左侧彩色边框表示日志级别
- 优化卡片内边距和行间距
- 增加微弱发光效果区分不同级别
- 优化悬停状态的视觉效果

#### 2.2 日志消息样式
- 优化时间戳、标签的显示位置
- 增加日志内容的可读性
- 支持更好的 JSON 格式化显示

### 3. 交互体验优化
**目标文件**: `web/app.css`

#### 3.1 工具栏优化
- 优化按钮的视觉反馈
- 增强选中/激活状态
- 优化下拉框和筛选控件

#### 3.2 分页组件优化
- 更清晰的页码显示
- 优化按钮悬停效果

### 4. 代码结构优化
**目标文件**: `web/app.css`

#### 4.1 CSS 变量系统化
- 将颜色值提取为语义化的 CSS 变量
- 添加注释说明每个变量的用途

#### 4.2 样式组织
- 按功能模块组织 CSS 代码
- 添加清晰的代码分区注释
