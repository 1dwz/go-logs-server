# 日志详情页标签实时更新 Bug 修复计划

## 问题描述

在日志详情页面中，标签列表不会实时更新。只有手动刷新页面（F5）才能看到新出现的标签。

## 问题根源

文件：`web/view.js`

- 第 365 行：`loadTags()` 只在页面初始化时被调用一次
- 第 248-272 行：自动刷新机制（EventSource）只负责接收新日志并调用 `renderLogs()` 更新日志列表
- **缺失**：没有在新日志到达时检查并更新标签列表

## 修复方案

在 `openEventSource()` 函数中，当收到新的日志条目时，检查其标签是否已在 `allTags` 数组中。如果不在，则添加新标签并重新渲染标签列表。

### 具体修改位置

修改 [view.js](e:\MyFiles\Program\AHK\Data\tools\src\logs-server\web\view.js) 中的 `openEventSource()` 函数（第 248-272 行）。

在处理新日志的代码块中（第 251-265 行），添加标签更新逻辑：

```javascript
eventSource.addEventListener('log', function(e) {
    var entry = JSON.parse(e.data);
    if (currentLogIds.indexOf(entry.id) !== -1) return;

    // 如果新日志有标签且不在 allTags 中，则添加
    if (entry.tag && allTags.indexOf(entry.tag) === -1) {
        allTags.push(entry.tag);
        allTags.sort();
        renderTags();
    }

    currentLogs.unshift(entry);
    currentLogIds.unshift(entry.id);
    totalLogs++;

    if (currentLogs.length > pageSize) currentLogs.pop();
    if (currentLogIds.length > pageSize) currentLogIds.pop();

    document.getElementById('logCount').textContent = String(totalLogs);
    renderLogs(currentLogs);
    renderPagination();
});
```

## 预期效果

- 当有新日志到达时，自动检查其标签
- 如果是新的标签，自动添加到标签列表并重新渲染
- 用户无需手动刷新页面即可看到最新的标签
- 标签按字母顺序排序（保持一致性）
