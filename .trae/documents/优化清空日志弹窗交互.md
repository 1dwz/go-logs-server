# 优化清空日志弹窗交互

## 问题分析

当前代码中存在以下问题：

1. **操作成功后显示"确认删除"按钮不合理**
   - 成功提示应该使用"关闭"按钮
   - 不应该再显示危险操作的删除按钮

2. **成功/失败后应该自动关闭或更新按钮状态**
   - 用户体验更好
   - 不需要用户手动点击关闭

## 修改方案

### 1. 创建通用的信息提示弹窗函数

修改 `view.js` 中的 `showConfirm` 函数，使其能够：
- 根据类型显示不同颜色的图标（成功用绿色，失败用红色）
- 根据类型显示不同的按钮（信息提示用"关闭"，危险操作用"确认删除"）
- 提供自动关闭功能

### 2. 修改 `clearLogs` 函数

- 成功提示：使用成功样式，自动关闭或显示"关闭"按钮
- 失败提示：使用错误样式，显示"关闭"按钮

### 3. 更新 HTML 结构

修改 `confirmModal` 中的按钮：
- 添加 `confirmBtn` 替代 `confirmOkBtn`，用于显示不同类型的按钮
- 按钮文字和样式根据弹窗类型动态变化

## 具体实现步骤

1. **修改 view.html**
   - 将确认按钮改为通用的 `confirmBtn`
   - 按钮文字根据类型变化

2. **修改 app.css**
   - 添加 `.btn.success` 样式（绿色）
   - 添加 `.btn.info` 样式（蓝色）

3. **修改 view.js**
   - 修改 `showConfirm` 函数支持类型参数
   - 添加自动关闭功能（使用 `setTimeout`）
   - 修改按钮文字和样式
   - 更新 `clearLogs` 函数调用

### 弹窗类型定义

- `confirm`: 确认操作 → 显示"取消"和"确认删除"按钮
- `success`: 操作成功 → 显示"关闭"按钮（绿色成功样式）
- `error`: 操作失败 → 显示"关闭"按钮（红色错误样式）
- `info`: 信息提示 → 显示"关闭"按钮（蓝色信息样式）
